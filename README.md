# 📚 Banco de Dados I - CEUB

Repositório dedicado ao armazenamento das listas de exercícios, práticas em laboratório, projetos e avaliações da disciplina de **Banco de Dados I** do Centro Universitário de Brasília (CEUB).

---

## 👨‍💻 Sobre o Repositório

Aqui você encontrará a organização dos códigos SQL, modelagens conceituais/lógicas e demais atividades desenvolvidas ao longo do semestre. O objetivo é documentar a evolução dos estudos e servir como material de consulta e revisão.
